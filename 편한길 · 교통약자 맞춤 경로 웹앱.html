실제 경로 API 연결

현재 상태: 실제 교통 API 미연결
임의의 시간·거리·환승 횟수는 더 이상 실제 경로 결과처럼 보여주지 않습니다. 실제 경로를 계산하려면 공공데이터를 수집하고 경로를 계산하는 서버가 필요합니다.

전국 연동을 위한 다음 단계

현재는 인증키가 없고 HTML 파일을 직접 여는 환경이므로, 이 화면만으로 실제 API를 호출할 수는 없습니다. 디자인은 유지하고 아래 순서로 연결하면 됩니다.

  1. 전국 경로 API부터 선택: TMAP 대중교통 API는 전국 대중교통 경로 탐색과 보행 구간 정보를 제공한다고 안내되어 있습니다. 앱 키가 필요하며 무료 체험 한도와 이용 조건을 먼저 확인하세요.
  2. 앱 키 발급: TMAP 대중교통 API 이용 절차에서 가입·앱 생성·이용 신청을 진행합니다. 비용이나 이용 승인이 필요한지 확인한 뒤 결정하세요.
  3. HTML을 로컬 웹 서버로 실행: 파일을 더블 클릭하는 file:// 방식 대신 프로젝트 폴더에서 개발용 서버를 실행합니다. API 키는 HTML/JavaScript에 넣지 않습니다.
  4. 백엔드 연결: 서버 환경변수에 키를 보관하고, /health와 /api/route를 구현합니다. 이 화면은 이미 그 두 엔드포인트를 호출하도록 준비되어 있습니다.
  5. 접근성 정보는 별도 검증: 일반 대중교통 경로가 휠체어 통행 가능을 보장하지는 않습니다. 엘리베이터·저상버스·단차·경사로 정보가 실제로 확인된 경우에만 근거와 갱신 시점을 표시하고, 모르면 ‘확인 필요’로 남깁니다.
연결 대기 중 — 서버 주소를 입력하면 /health 연결을 확인합니다. 경로 검색은 서버의 POST /api/route 엔드포인트를 사용합니다.
